Signal Prototype Gallery

A dark instrument chassis for reading finished agent runs: neutral chrome, hue reserved for run status, one cyan accent spent only on the traced critical path. Locked as the visual anchor from direction C of the upstream prototyping-ui-directions run, then applied across three surfaces. Every surface here was checked by scripts/validate_surface.py; the deterministic gates are real results, the soft grades are deliberately ungraded. All mocks built against the Signal chassis (Inter / radius 6px / hairline borders / single mono accent oklch(0.78 0.16 190) / no glass / no aurora / no glow), aligned to MVP function inventory. This gallery is the entry point for visual review before Gate 12.
